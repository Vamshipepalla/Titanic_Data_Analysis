# 🚢 Titanic Data Analysis

> Exploring passenger data. Discovering patterns. Understanding survival.

## About the Project

This project explores the Titanic passenger dataset using Python and Exploratory Data Analysis (EDA). The goal is to clean the data, identify patterns, and understand how survival rates differed across passenger groups.

## Objectives

- Clean the dataset and handle missing values.
- Analyze passenger demographics and travel details.
- Compare survival rates by gender and passenger class.
- Create useful features for deeper analysis.
- Visualize patterns and relationships in the data.

## Tech Stack

- **Python** — Data analysis
- **Pandas & NumPy** — Data cleaning and manipulation
- **Matplotlib & Seaborn** — Data visualization
- **Jupyter Notebook** — Interactive analysis

## Key Analysis

- Passenger age, gender, and class distribution
- Survival rates across passenger groups
- Missing-value handling and feature engineering
- Data visualization and correlation analysis

## Key Findings

- Female passengers had a higher survival rate than male passengers in the analyzed dataset.
- First-class passengers had a higher survival rate than second- and third-class passengers.
- Data cleaning and visualization helped reveal patterns in passenger information.

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Vamshipepalla/titanic-data-analysis.git
```

**2. Open the project folder**

```bash
cd titanic-data-analysis
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `Titanic.ipynb` and run the cells. Keep `Titanic Data Set.csv` in the same folder as the notebook.
